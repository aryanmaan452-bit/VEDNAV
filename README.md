# VEDNAV

VEDNAV is a skincare storefront preview with an interactive WebGL pond, a browsable concept collection, a wishlist, and a separate account demo.

Move your pointer across the water, tap the pond, or use **Feed the fish**. The fish follows the lure, then leaps and sends ripples across the surface. The water uses animated reflections and caustics. Reduced-motion settings show a still pond.

## Preview

[Open VEDNAV](https://aryanmaan452-bit.github.io/VEDNAV/)

This repository hosts the prebuilt Vite site on GitHub Pages. The storefront is at `index.html`, the account demo is at `account/index.html`, and `theme.js` is shared by both pages.

Products and prices are illustrative. The preview does not process payments or create real accounts.
